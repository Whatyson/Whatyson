# Olá, eu sou Whatyson 👋

Desenvolvedor de software com **mais de 20 anos** construindo sistemas que rodam no mundo real: ERPs, PDVs, integração fiscal e automação comercial. Comecei em Delphi/Pascal, atravessei o boom mobile e hoje vivo no ecossistema **.NET / C# / ASP.NET Core / Blazor Hybrid**, sem largar Python, Dart/Flutter e TypeScript pelo caminho.

- **Farmácia** — controle de medicamentos controlados e integração com **SNGPC**.

## 🎯 Como trabalho

Prefiro sistemas que **funcionam de verdade em produção** a arquiteturas bonitas no papel. Gosto de mudança cirúrgica, código simples e decisão técnica bem justificada — 20 anos de campo ensinam que complexidade desnecessária é quem paga a conta é o cliente, não o desenvolvedor.

Na prática: Clean Architecture pragmática, testes de contrato contra o schema real do banco, scripts SQL numerados e versionados, offline-first onde a rede não é garantida e documentação de progresso viva em cada projeto.
