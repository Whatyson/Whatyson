# Olá, eu sou Whatyson 👋

Desenvolvedor de software com **mais de 20 anos** construindo sistemas que rodam no mundo real: ERPs, PDVs, integração fiscal e automação comercial. Comecei em Delphi/Pascal, atravessei o boom mobile e hoje vivo no ecossistema **.NET / C# / Blazor Hybrid**, sem largar Python, Dart/Flutter e TypeScript pelo caminho.

## 🛠️ O que eu faço

- **Sistemas de PDV e ERP** — frente de caixa offline-first, sincronização com backend, emissão fiscal (NFC-e, contingência, SAT).
- **Saúde** — sistemas de gestão para clínicas e hospitais (agenda, prontuário, faturamento).
- **Logística** — sistemas para transportadoras, com emissão de **CT-e** e **MDF-e**.
- **Farmácia** — controle de medicamentos controlados e integração com **SNGPC**.
- **Fiscal** — emissão e integração de **NF-e, NFS-e, CT-e, MDF-e, NFC-e/SAT**.
- **Modernização de legado** — migração de sistemas Delphi/Pascal para arquiteturas .NET modernas, mantendo compatibilidade operacional.
- **Mobile** — apps de gestão e atendimento em Flutter/Dart.
- **Automação e dados** — scripts e ferramentas em Python para extração, leitura e processamento de documentos.

## ⚙️ Stack

`C# / .NET` · `Blazor Hybrid` · `Delphi / Pascal` · `Dart / Flutter` · `Python` · `TypeScript` · `SQL Server`

## 🎯 Como trabalho

Prefiro sistemas que **funcionam de verdade em produção** a arquiteturas bonitas no papel. Gosto de mudança cirúrgica, código simples e decisão técnica bem justificada — 20 anos de campo ensinam que complexidade desnecessária é quem paga a conta é o cliente, não o desenvolvedor.
